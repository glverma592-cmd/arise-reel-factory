# 🎬 Reel Studio Kit

Claude se **Reel** banao — na timeline, na cutting, na ghanton ki mehnat. Sirf **3 steps**.

## Step 1 — Kit
Ye ZIP download karke **Extract** kar lo. Andar `reel-studio-kit` folder milega.

## Step 2 — Claude Code Setup
1. **Claude Code** kholo (desktop app ya terminal) aur `reel-studio-kit` folder select karo.
2. Pehli line likho:

   > **इस फोल्डर का सेटअप करो।**

   Claude khud **Node.js, Python aur FFmpeg** install/check karega, aur aapka brand naam poochhega. ✅ Setup complete.

## Step 3 — Generate the Reel
Bas likho:

> **Reel बनाओ — <apna topic>**

Claude khud karega: **Research → Script → AI Voiceover → Animation & Captions**, aur 1080×1920 video ready
(`projects/<topic>/reel_v1.mp4`), saath me thumbnail, captions file aur Instagram caption + hashtags.

### Pasand nahi aaya? Bas bolo
- "Hook aur punchy karo"
- "30 second ki karo"
- "Female voice lagao"
- "English me banao"
- "Mere brand ke colors lagao"

Har edit ek naya version banata hai (`reel_v2.mp4`…), purana delete nahi hota.

### Zaroori
- Claude Code (Claude Pro/Max plan ya API) — https://claude.com/claude-code
- Internet (research aur AI voice ke liye)
- Windows / Mac / Linux, aur Chrome ya Edge browser

### Background music
Koi bhi copyright-free `.mp3` `assets/music/` me daal do — reel me halki volume par apne aap lag jayegi.

### Kuch atka?
Claude Code me hi likho: **"setup check karo"** — wo `scripts/check_setup.py` chala ke theek kar dega.
